# 아이디어: 파밍 루프 (아직 아이디어 단계 - 구현 결정 전)

기록: 2026-10-08, 사용자 아이디어 정리. 구현할 때 다시 논의해서 확정한다.
디아블로는 **구조만 참고**하고 이름·수치·문구는 우리 것으로 만든다 (CLAUDE.md 규칙 6).

## 핵심 생각

- 디아블로의 핵심: 레벨업은 기본이고, 그 뒤에 **원하는 아이템을 맞춰 "졸업"하는 것**.
- 플레이어가 실제로 하는 일은 **반복 파밍**이다. 재미는 슬롯머신처럼 나오는 결과에서 온다.
  - 아이템 종류·등급
  - 옵션 수치(굴림 범위)
  - 소켓, 룬(에테) 같은 추가 변수
  - 꽝(잡옵·낮은 굴림)의 존재 - 꽝이 있어야 대박이 빛난다
- 레벨업은 **지금처럼 웨이브 방식**으로 한다(현재 목장 6웨이브 + 레벨업 카드).

## 파밍 맵

- 파밍 전용 맵을 **5~8개** 만든다. 각 맵이 디아의 "카생 런", "매피 런" 같은 반복 사냥 코스 역할을 한다.
- 맵마다 정해 두는 것:
  - **난이도 단계**: 난이도별로 아이템 테이블과 드랍률이 달라짐
  - **몬스터 강함**
  - **면역**: 물리 면역, 화염·냉기·번개·독 각 원소 면역
- → **내 빌드에 맞는 사냥터를 고르는 판단**이 생김 (예: 화염 마법사는 화염 면역 맵을 피함).

## 반복 파밍 편의

- 같은 맵을 100번씩 돌리니 **회차 수를 표시**한다. 예: "이 맵 37회째", 맵별 누적 회차.
- 덧붙일 만한 것: 이번 회차 / 누적 획득 요약(전설 몇 개 등) - 기록 자체가 동기 부여.

## 나중 단계 (온라인)

- **거래**: 트레이더리 같은 유저 간 교환 기능.
- **자랑 게시판**: 내 전리품을 올려 자랑하는 곳.
- 둘 다 서버·계정·저장(지금은 localStorage만)이 필요하다. 아이템 위조 방지(서버 검증)도 고민해야 한다.

## 소켓·룬 설계안 (2026-10-08 - 나중에 작업, 아직 코드 없음)

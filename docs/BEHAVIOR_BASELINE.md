# BEHAVIOR_BASELINE — "동작이 안 바뀌었다"를 증명하는 기준

리팩토링의 합격 기준은 **게임이 지금과 똑같이 동작하는 것**이다. 이 문서는 그 기준과 확인 방법이다.

## 1. 자동 확인 도구 (`legacy/tools/`)

레거시 HTML을 브라우저 없이 Node(vm)에서 돌린다. (`npm i matter-js@0.20.0` 필요)

```bash
node legacy/tools/smoke.cjs                  # 150초 분량 무작위 입력 + 장비창 클릭 난사. 예외/NaN 없으면 통과
node legacy/tools/smoke.cjs legacy/cow_pen.html 777   # 다른 시드로
node legacy/tools/baseline.cjs --check       # 현재 동작이 docs/baseline.golden.json과 같은지 (레거시 자체 점검)
node legacy/tools/baseline.cjs --write docs/baseline.golden.json   # (레거시 동작을 일부러 바꿨을 때만) 골든 갱신
```

- `baseline.golden.json`은 **레거시 동작에서 뽑은 골든 마스터**다. `exact` 항목은 값이 정확히 같아야 하고,
  `statistical` 항목(드랍/등급 분포, 시드 고정 30,000회)은 ±1.0%p 이내여야 한다.
- 이 도구들은 레거시 파일의 스크립트 스코프에 코드를 덧붙여 실행하는 방식이라 **새 모듈 코드에는 그대로 못 쓴다.**
  새 코드에서는 `tests/`에 Vitest로 같은 값을 계산해서 `docs/baseline.golden.json`과 비교하는 테스트를 만든다
  (골든 JSON을 그대로 읽어서 비교할 것 — 숫자를 테스트 코드에 복사해 넣지 말 것).
- 새 코드용 스모크 테스트: jsdom(또는 최소 DOM 스텁) + Canvas 2D 스텁(어떤 메서드든 no-op, `measureText`는 `{width}`,
  `createLinearGradient/createRadialGradient`는 `{addColorStop}`, **숫자 인자에 NaN/Infinity가 들어오면 throw**) + rAF 콜백을
  직접 호출해서 프레임을 진행. `legacy/tools/_sandbox.cjs`가 같은 방식의 참고 구현이다.

## 2. 골든 JSON이 보장하는 것 (`exact`)

| 키 | 내용 |
|---|---|
| `monsters` | 11종 몬스터의 hp / 근접 데미지 / 크기 배율 (보스 78, 강화 9, 자폭 3, 나머지 6) |
| `baseDamage`, `hitsToKill` | 기본 데미지 3, 데미지별 타수(작은 몬스터 2방·큰 몬스터 3방 구조) |
| `progression` | 레벨업 누적 경험치(130/524/1278/2473…), 레벨당 5포인트, 포인트당 효과, 스킬 해금 레벨 |
| `start` | 시작 상태: 체력 15, 슬롯(공격+함성), 물약 2/2, 한손무기+방패(감정됨), 테스트 가방 7개 |
| `slot2OptionsByLevel` | 레벨별로 슬롯2에 올릴 수 있는 스킬 |
| `weaponRange`, `arcDegSingle/Dual` | 무기별 사거리(검 50/도끼·메이스 46/단검 38/창 68/맨손 50), 공격각(한손 111.6°/쌍수 162°) |
| `equipRules` | 양손무기↔방패 상호배제, 보조슬롯 잠금 |
| `identify` | 드랍은 미감정, 감정 0.8초, 감정 전 장착 불가 |
| `potions` | 가득 찼을 땐 소모 안 함, 생명=최대체력 50%(올림), 마나 +60, 종류별 쿨다운 1.2초, 보관 한도 6 |
| `whirlwind` | 간격 0.4초, 최악 조건(4마리 가둠)에서 작은 놈 0.43초/큰 놈 0.85초에 사망 |
| `waveSizes`, `bossWave` | 웨이브별 몬스터 수 [10,14,18,22,26,5], 보스 웨이브 6 |
| `rarity`, `statDef`, `dropConstants` | 등급 가중치/배율, 옵션 범위, 드랍·강화 상수 |

## 3. 자동으로 못 잡는 것 — 사용자 수동 플레이 체크리스트

각 STOP 지점(BRIEF 참조)에서 사용자가 직접 확인한다. 에이전트는 **"실제 브라우저 플레이는 확인하지 못했다"**고 보고에 명시할 것.

**흐름**
- [ ] 첫 로드 → 타이틀(PRESS START) → Space/클릭으로 시작 → 4초 "전투 준비" 카운트다운 → 웨이브 1 배너
- [ ] P/ESC 일시정지·해제, 사망 후 아무 행동키로 재시작, 보스 처치 시 승리 화면, 최고 기록(localStorage) 갱신
- [ ] `L` 키 = 한 레벨 업 (테스트용), 레벨 2/3/4/5에서 "새 스킬 해금" 문구

**전투**
- [ ] Space/좌클릭 길게 = 슬롯1 반복 시전, E/우클릭 길게 = 슬롯2, Q/R로 슬롯 스킬 전환
- [ ] 한손+방패일 땐 방패 쪽이 휘두르지 않음, 쌍수일 땐 양손 모두 휘두름
- [ ] 휠윈드가 한 번에 몰살하지 않고 0.4초 간격으로 타격
- [ ] 보스를 어느 방향에서든 때릴 수 있음
- [ ] 몬스터 11종 각각의 특수 행동 (버닝 불바닥, 자폭 점화 후 폭발, 주술사 후퇴+치유, 번개 충전 후 직선 빔·옆으로 피하면 회피, 돌진 예고선, 냉기 노바, 광신 오라)

**아이템/메뉴**
- [ ] 바닥 아이템이 글자 칩(무기/방어구/장신구/재료/…물약)으로 표시, 주우면 가방에 "미감정"
- [ ] I 또는 우측 상단 버튼으로 메뉴 열기(월드 정지), 4탭(장비/스탯/가방/강화) 전환
- [ ] 가방: 클릭하면 고정(마우스를 옮겨도 유지), 같은 칸 다시 클릭하면 해제, 올려두면 미리보기, 감정하기→등급색 번쩍임, 장착하기
- [ ] 스탯 탭 `+`, 강화 탭 `강화` 버튼, 키보드 Z~M / 1~7
- [ ] 물약먹기(1키)/마나먹기(2키) 버튼과 개수 표시, 쿨다운 오버레이

**모바일**
- [ ] 조이스틱 이동, 슬롯 버튼 길게 누르기, ⟳ 전환 버튼, 물약 버튼, 전체화면 버튼
